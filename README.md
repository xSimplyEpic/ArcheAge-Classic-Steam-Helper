# ArcheAge Classic Steam Helper

A lightweight launcher utility for **ArcheAge Classic** that improves **Steam compatibility**, allows switching between **ArcheAge** and **ArcheAge: Unchained**, and provides a cleaner launch experience.

## Features

- ✅ **Steam Compatibility Mode**
  - Launch ArcheAge Classic through Steam compatibility.

- ✅ **ArcheAge / Unchained Switching**
  - Choose between:
    - ArcheAge
    - ArcheAge: Unchained
    - Auto Detect

- ✅ **Automatic Ownership Detection**
  - Detects owned Steam licenses and displays compatibility status.

- ✅ **Steam Library Detection**
  - Automatically detects Steam install paths.

- ✅ **Game Detection**
  - Detects ArcheAge Classic installation automatically.

- ✅ **Manual Override Support**
  - Manually configure Steam or game paths if detection fails.

- ✅ **Persistent Settings**
  - Saves preferred Steam compatibility selection.

- ✅ **Discord & Wiki Quick Access**
  - One-click access to:
    - Official Discord
    - ArcheAge Classic Wiki

- ✅ **Modern Custom Launcher UI**
  - Clean MMO-style interface with hover animations and status indicators.

## How It Works

ArcheAge Classic Steam Helper prepares Steam compatibility and launches the official ArcheAge Classic launcher while supporting Steam ownership detection and compatibility spoofing.

This allows users to:

* Display game activity in Steam
* Use Steam overlay
* Launch through a preferred Steam version
* Seamlessly switch compatibility modes

---

## Installation

### Download Release

Download the latest release from:

**Releases → Latest Version**

---

### Install

1. Download the installer or release package.
2. Run:
   
```
ArcheAgeClassicSteamHelper.exe
```

3. Launch the helper.
4. Click **Play**.

The application will automatically:

* Detect Steam
* Detect ArcheAge Classic
* Apply Steam compatibility mode
* Launch the game
